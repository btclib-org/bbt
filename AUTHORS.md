# Authors

To see the list of bbt authors for copyright purposes, see the revision
history in source control:
<https://github.com/btclib-org/bbt/graphs/contributors>

The graph is this repository's own and not the organization's, and the
history it holds is older than the repository itself:
`git log --format=%ad main | tail -1` dates the first commit and
`gh api repos/btclib-org/bbt --jq .created_at` dates the repository. So
the graph carries authors who never pushed here.

The screenshots under `lab-tutorial/image/` are of bitaddress.org, a key
generator other people wrote, and the interface in them is theirs.
