# Release notes

What a user has to *act* on, and nothing else: a breaking change, a
migration, a default that moved under them. Everything a reader would
merely notice is in [CHANGELOG.md](./CHANGELOG.md), which is the record
behind this file.

## Unreleased

Nothing a user has to act on: this repository publishes nothing and ships
by being read. What changed for somebody working *in* it — five
configuration files replaced by one, a lint gate where there was none —
is in the changelog, and `CONTRIBUTING.md` carries the commands.
